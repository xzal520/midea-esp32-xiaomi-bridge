## 内容与素材

视频讲解利用美的原显示板 Wi-Fi 模块接口，通过 ESP32-S3 与米家空调拆机模块进行串口协议转换，并提供 HomeKit 接入的过程。

使用了本目录的 `操作视频.mp4`、`网页.mp4`、`实物照片.jpg`、`web控制页.png` 和 `homekit.png`。接线、协议流程、风速映射和问题分析画面重新绘制；代码片段来自主卧项目 `midea_s3_bridge.ino` 与 `miot_bridge.h`，为画面可读性简化了转换语法和外围逻辑。

实机适配组合由项目使用者确认：美的 i青春Ⅱ + 小米巨省电 1.5 匹空调拆机米家模块。其他拆机模块的属性与功能可能不同，需要根据实际 model 和抓包结果适配。

视频中的 1–100 是美的协议风速值，不代表已测得的实际转速百分比。片中介绍的是空调原生倒计时；美居云端预约不由 ESP32 同步执行。没有把 RAM 模拟的机组体检、目标湿度和干燥描述为美的硬件功能。

## 重新制作

`make_1080p.py --voice` 读取 `1080P-分镜与旁白稿.md` 并生成逐段中文语音；文案变化时按内容签名更新对应音轨，需要项目 `build/video-python` 中的 edge-tts 依赖和网络。

`make_1080p.py --build` 生成音乐、分镜、字幕和视频，需要 Pillow、NumPy、imageio-ffmpeg。渲染缓存位于项目 `build/video-1080p`，素材或分镜变更后需清除对应 `clip-xx.mp4` 缓存再生成。

用户编辑的分镜与旁白稿保持原样；生成的时间轴单独保存在 `1080P-分镜与旁白稿-生成时间轴.md`。按当前配音长度分配各场景时间，保持全片 120 秒。本次同步更新倒计时三端显示和结尾的详细教程发布说明；稿件中的“👉”在生成配音与字幕时转换为“通过”，原稿不改。
