# ESP32-S3 主卧项目介绍视频

本目录包含一版简体中文项目介绍视频、配音、字幕和封面。内容以 `ESP32-S3-主卧/README.md` 与功能说明为准，重点介绍本地串口桥接、真实状态回读、自定义风速、美的原生倒计时、HomeKit、BLE 和网页串口诊断。

视频没有使用真实设备的 IP、Wi-Fi 密码、HomeKit 配对码、二维码或账号信息。日志画面是示意图。网页预约已经移除；美居云预约不会自动同步到 ESP32 网页。

## 文件

- `ESP32-S3-主卧项目介绍.mp4`：1920×1080，画面中文字幕与原创合成背景音。
- `ESP32-S3-主卧项目介绍.srt`：简体中文字幕。
- `旁白稿.md`：逐场景中文旁白，可录制后替换背景音轨。
- `封面.png`：视频封面。
- `generate_video.py`：视频生成脚本，使用本机中文系统语音、Pillow 和 imageio-ffmpeg。

在 Windows 上运行 `python generate_video.py` 可重新生成视频。需要安装 Pillow、NumPy 和 imageio-ffmpeg。
