# 自然配音与配乐版

- 旁白：Microsoft zh-CN-XiaoxiaoNeural（晓晓），语速 -6%，不变调。经用户授权向微软在线语音服务提交教程讲解稿。
- 字幕：根据新语音的逐词时间戳重新对齐，保留原讲解稿标点。
- 配乐：Kevin MacLeod 的《Clear Air》，木吉他和钢琴；CC BY 4.0，署名见片头及《背景音乐署名与来源.md》。基础响度约 -29 LUFS，讲解时自动压低。
- 画面：保留 49 步讲解、7 章、实物接线图及《固件刷写.mp4》录屏；根据新旁白长度重新安排停留时间。
- 输出：1920×1080 / 25 FPS，H.264 / AAC 立体声，附 60 秒试听、独立字幕和章节时间轴。

重新制作：先运行 `synthesize_natural.py`（需要网络），再运行 `make_natural_audio.py`。旧版本位于上一级目录。

## 关注片头

## 重音修复与配乐替换

片头原有 350 ms 的左右声道延迟差已修正。人声从无配乐母版重新提取，统一左右声道起点，并从头至尾替换原背景音乐。运行 `remix_clear_air.py` 可重建此修正版。
