## 片头

教程开始前，帮忙点个关注吧。后续继续分享智能家居实用教程。

## 00:08 从接线到日常使用

这期视频按照安装教程，从零完成美的空调接入米家和苹果家庭。我们先确认显示板接口，再逐根接线，使用电脑刷写固件，最后配置网络和各项功能。看到重要接线表或输入参数时，可以暂停视频，核对后再继续。

## 00:33 先看这里：必须有 Wi-Fi 接口

开始前先看这张美的显示板照片。左下方已经焊上线的位置，就是本教程使用的无线模块接口。你的显示板也要有对应接口，而且引脚和电平需要确认适配。没有这个接口，或者接口定义不明确，就不能直接照搬后面的接线。

## 00:58 准备开发板、模块和工具

准备适配本项目的 ESP32 S3 MINI、米家空调拆机模块，以及可以传输数据的 USB 线。还需要两组与实物接口匹配的四芯线束、万用表和绝缘固定材料。线束外形相似并不代表针脚相同，不能只按线的颜色连接。

## 01:22 断电拆开，记录原有接线

拆装之前先断开空调市电。打开面板后，先拍下原有插头方向和线束位置，再找到显示板盒。不要带电插拔或焊接。接下来展示的是这台主卧设备的安装位置，不同机型的布局可能不同。

## 01:44 先认识整个连接关系

整个结构是美的显示板连接 ESP32，ESP32 再连接米家模块。它使用两组独立串口。下面所有接收和发送，统一以 ESP32 为参照：对方发送接 ESP32 接收，ESP32 发送接对方接收。两端还必须有共同的信号地。

## 02:10 先测电源和串口电平

先用万用表确认电源和地，再检查串口信号电平。本项目按三点三伏逻辑设计；模块上的五伏字样不能代替实测。如果信号超过 ESP32 允许范围，要先做电平转换。不要把五伏电源接到任何 GPIO 引脚。

## 02:34 第一根：美的 TX → GPIO17

先连接美的这一侧。确认空调无线接口的发送脚，把它接到 ESP32 的十七号引脚。十七号在这里是接收端，负责读取空调回包。美的串口使用九千六百波特、八位数据、一位停止位和无校验。

## 02:57 第二根：GPIO16 → 美的 RX

第二根线，把 ESP32 的十六号发送脚接到空调侧的接收脚。请再次核对：十七号收，十六号发。如果还保留原装美的无线模块，原装模块的发送端不能直接和十六号并联，要通过可靠的隔离或切换电路避免同时驱动。

## 03:21 找对米家模块的业务串口

再看米家拆机模块。我们需要的是它和空调主控通信的业务串口，不是零号发送、零号接收的启动日志口。以这块模块为例，业务口标为主控发送和主控接收。请结合丝印、走线和测量确认，不按颜色猜测。

## 03:45 第三、四根：连接米家串口

把米家模块的业务发送脚接到 ESP32 的七号接收脚；再把 ESP32 的八号发送脚接到模块的业务接收脚。本次实物中，模块端业务发送和接收分别对应十七号与十六号。米家串口速率是十一万五千二百。

## 04:08 接好公共地，再做逐项检查

接好经过确认的供电，并将信号地连接到一起。通电前，逐根检查导通、短路和虚焊，再检查焊点是否绝缘。刷机时让 ESP32 单独通过 USB 供电，先断开空调和其他外部供电，避免几路电源同时接入。

## 04:31 接线表：暂停核对后再刷机

现在暂停一下，按这张表核对四根串口线。美的发送到十七号，美的接收接十六号。米家发送到七号，米家接收接八号。确认公共地、电源和逻辑电平都正确后，再进入刷写步骤。

## 05:00 下载工具和正确的固件

首次刷写使用乐鑫官方的图形下载工具。在教程里下载并解压工具，然后从夸克网盘获取对应板卡的完整十六兆镜像。文件名应包含完整刷写镜像的标记。不要把网页升级用的应用镜像，当作完整镜像直接从零地址刷入。

## 05:25 只用 USB 连接 ESP32

让 ESP32 单独用 USB 连接电脑。在 Windows 设备管理器的端口列表里，查看新出现的串口号。录屏里出现的 COM 七只是示例，你应该选择自己的实际端口。若只有供电却没有端口，先更换支持数据传输的 USB 线。

## 05:49 录屏步骤一：启动下载工具

下面使用你提供的固件刷写录屏。打开解压后的下载工具，芯片选择 ESP32 S3，工作模式选择开发模式。下载方式根据实际连接选择，原生 USB 与 USB 转串口并不完全相同。录屏里的固件版本和端口是示例，以本次下载和实际硬件为准。

## 06:17 录屏步骤二：选择完整固件

在下载页第一行点文件选择按钮，找到完整十六兆固件。选中后，勾选这一行左侧的小方框。完整镜像已经包含启动与分区等必要内容，所以这里只勾选这一行。后面的录屏会继续展示参数设置和写入过程。

## 06:40 录屏步骤三：地址必须是 0x0

这一项最容易遗漏：在第一行艾特符号右侧的地址框里填写零叉零。完整镜像从闪存起始地址写入。文件路径选好了，也必须填写地址；地址框为空或标红时不要开始。完整镜像会覆盖原有设置和配对记录。

## 07:04 录屏步骤四：端口、波特率与 START

下方串口选择自己的端口，波特率可以先使用十一万五千二百。如果提供不改变固件参数的选项，按教程勾选。核对芯片、文件、地址和串口后，点击开始。若连接超时，可以按住启动键，再按复位键，进入下载模式后重试。

## 07:29 录屏步骤五：等待写入完成

开始写入后保持供电和数据连接稳定，不要拔线或关闭工具。这里保留录屏中的实际写入过程。看到进度变化并不代表已经完成，要继续等到工具明确显示完成。如果中途失败，先检查线缆和供电，再根据错误信息处理。等待时也可以记住这几个排查顺序。找不到串口，先检查数据线和设备管理器；停在等待连接，检查端口以及是否进入下载模式；已经开始传输却反复中断，优先检查供电和数据线。记录具体报错后再重试，不要在正常写入期间点击停止或复位。首次完整刷写可能覆盖原有网络和配对信息，完成后还要按照下一章重新确认联网。

## 08:40 录屏步骤六：FINISH 后复位

工具显示完成后，再退出下载工具并复位开发板。也可以断开 USB 后重新上电。录屏中的 MAC 地址和固件版本不需要照抄。到这里，刷写步骤完成，接下来让 ESP32 连接家里的无线网络。

## 09:03 三种入口，按设备状态选择

配网可以按设备状态选择。已经连接路由器时，直接打开管理网页。还没联网时，可以用蓝牙网页把无线网络信息发送给设备。如果持续连不上路由器，也可以使用设备自动开启的临时热点。这里设置的是 ESP32 自己的网络。

## 09:28 蓝牙配网一：打开正确的网页

先打开教程网页，在顶部切换到蓝牙配网。网页需要使用安全的 HTTPS 地址，或者电脑本机地址。安卓可以用支持网页蓝牙的 Chrome，苹果手机可以尝试 Bluefy。普通浏览器没有网页蓝牙能力时，页面无法替它增加这个功能。

## 09:53 蓝牙配网二：选择设备并确认

给设备通电，打开手机或电脑的蓝牙并靠近设备。点击连接蓝牙设备，在浏览器列表中选中名称以 Midea S3 Bridge 开头的目标。出现系统配对提示时确认。Windows 如果首次加密配对失败，可以先在系统蓝牙设置里配对，再回到网页连接。

## 10:19 蓝牙配网三：先验证设备身份

连接成功后，输入设备当前的网页登录密码，点击验证并继续。这个密码用于验证你有权配置这台设备，不是家里的无线网络密码，也不是设备热点密码。设备以前改过网页登录密码时，要使用修改后的密码。

## 10:42 蓝牙配网四：选择 SSID 并保存

验证通过后等待扫描，从列表选择家里的二点四 G 无线网络，再输入它的密码。隐藏网络可以手动填写名称，开放网络可将密码留空。点击保存并重启后确认，等待设备启动并连接新网络。附近网络扫描需要支持该功能的固件。

## 11:07 热点配网一：等待临时热点

如果蓝牙不方便，也可以通过设备热点配置。支持此功能的固件，在连续无法连接路由器大约九十秒后，会启动临时热点。到手机无线设置中，连接屏幕上的热点名称。热点密码来自这台固件的配置，和其他两个密码分别设置。

## 11:32 热点配网二：打开 192.168.4.1

保持连接设备热点，在浏览器地址栏输入一九二点一六八点四点一。页面中填写家里二点四 G 网络的名称和密码，还要填写设备当前的网页登录密码。提交后等待重启，然后把手机重新连接到家里的无线网络。

## 11:55 打开设备管理网页并登录

ESP32 联网后，让手机或电脑连接同一局域网。在地址栏输入默认的本地域名。如果域名无法解析，到路由器设备列表找出 ESP32 的地址，用它的 IP 打开。输入当前网页登录密码完成登录，之后就能看到五个管理功能页。

## 12:20 先认识五个管理页面

设备网页顶部共有五个功能页。空调控制负责日常操作；智能接入管理苹果家庭和米家；设备状态查看运行和网络信息；串口调试用来定位通信问题；设置里调整网络、风速映射、访问密码、蓝牙和固件。

## 12:44 空调控制：开关、温度、模式

先看空调控制页。点击开机或关机，用温度旁的加减按钮调整设定温度。切换模式后，查看当前模式和状态是否随实际空调更新。如果需要主动刷新，可点击查询状态。指令发送出去和空调已经执行，是两个阶段。

## 13:08 风速、摆风、ECO 与睡眠

当前风速可以在模式与风速区域切换。舒适功能里可以操作上下摆风、节能和睡眠。不同空调的支持范围可能不同，所以要查看真实回包和空调动作，而不是只看按钮已经按下。自动运行模式下，单独调风速可能不会改变实际转速。

## 13:34 设置开机、关机倒计时

倒计时区域分开设置开机和关机。填写小时与分钟后，点击对应设置按钮，再查询空调回报的剩余时间。需要取消时，点对应的取消按钮。它表示从现在起多久以后动作，并不是每天几点或者每周重复执行的预约。

## 13:58 在管理网页更换 Wi-Fi

设备已经联网时，进入设置里的无线连接设置，点击扫描网络，选择目标网络或手动填写名称。输入新网络密码后，点击保存并重启并确认。设备大约三秒后重启；手机也要切换到新网络，再通过域名或新 IP 访问。

## 14:22 七档风速：逐档填写映射值

进入米家七档风速映射，可以指定每一档对应的美的协议风速值。七个值必须是一到一百的整数，并从第一档到第七档严格递增。先从默认值开始调整，每次小幅修改并观察实际效果。这些数值不是实测转速百分比。

## 14:46 风速映射：保存与恢复默认

填好后点保存映射。保存不会立刻改变当前风速，下次调档和状态回读会采用新表，重启后也会保留。要恢复出厂映射，先点击恢复默认，再点击保存。自动档固定使用协议值一百零二，不包含在七个手动数值里。

## 15:11 修改设备网页访问密码

在修改网页登录密码区域，先填当前密码，再填新密码并确认一次，按页面要求使用六到六十四个字符。点击保存后，密码保存在设备中。以后网页登录和蓝牙认证都使用新密码，原有网页会话可能需要重新登录。视频不展示真实密码。

## 15:37 主机名与 .local 访问地址

网络名称有两个独立字段。主机名用于向路由器报告名称，可以使用中文。访问地址只填写点 local 前面的部分，使用英文字母、数字和短横线，首尾不能是短横线。保存后设备重启，再使用新地址；IP 仍然是备用入口。

## 16:02 管理 BLE 蓝牙开关

蓝牙功能开关在设置页底部。开启或关闭后设备会短暂重启生效。关闭蓝牙后，配网页面和蓝牙应用就无法发现设备；如果以后还需要蓝牙，可以在设备已经联网的管理网页里重新开启。

## 16:24 HomeKit 一：找到配对入口

添加苹果家庭前，先确认 ESP32 和手机都连接到家里的同一局域网。打开设备网页的智能接入，在苹果家庭卡片查看配对状态、二维码和配对码。要使用自己设备显示的信息。视频里的示意区域不会提供可用的真实配对码。

## 16:49 HomeKit 二：在家庭 App 添加配件

打开手机上的家庭应用，选择添加配件。可以扫描另一个屏幕上显示的设备二维码，也可以按应用提示手动输入设备配对码。完成房间和名称设置后，尝试控制开关和温度，并观察实际空调和网页状态是否一致。

## 17:12 HomeKit 三：重新配对的正确顺序

需要重新配对时，在设备网页清除苹果家庭配对，再到家庭应用移除旧配件，最后重新添加。当前接口支持关机、制冷、制热和自动；除湿与送风可以在设备网页操作。不要把重新配对和重新设置无线网络混为一件事。

## 17:37 米家模块：先检查通信状态

在智能接入的米家模块区域，先看串口是否识别到模块，再看网络与协议握手。必要时点击同步美的状态。ESP32 和米家模块各自有网络配置；ESP32 已经联网，不代表拆机模块也已经加入米家。

## 18:00 米家模块：重新进入配网

需要重新添加米家模块时，点击进入米家模组配网，再回到米家应用按提示添加。这个操作清除的是外接米家模块原来的无线配置，不是 ESP32 的路由器配置。完成后再测试开关、模式、温度和风速，检查网页状态同步。

## 18:25 设备状态：查版本、IP 和信号

设备状态页可查看固件版本、运行时间、CPU 估算负载、内存和应用空间。网络部分可以查到当前 IP、本地域名、信号强度和蓝牙连接。打不开域名时，先通过这里或路由器记录的 IP 访问，不要直接判断设备已经损坏。

## 18:51 串口日志：看清数据方向

串口调试页显示两侧通信。接收表示 ESP32 收到，发送表示 ESP32 发出；每行还会标明来源和方向。遇到控制失败时，先看指令有没有发送、空调有没有有效回包。记录出问题的时刻、操作和日志，再做下一步排查。

## 19:16 高级调试：独立 RX 与模拟开关

独立接收模式会把十六号引脚改为接收，并暂停向美的发送；调试完成应恢复。脱机模拟用于没有连接空调时测试米家和苹果家庭，不会执行真实硬件动作。测试上报与扩展属性模拟，也不能当作真实传感器或空调功能。

## 19:41 以后更新：只上传网页 OTA 镜像

日常升级不需要再使用完整刷写。进入设置中的固件更新，选择对应板卡的网页 OTA 应用镜像，上传并确认。保持网络和供电稳定，等待设备重启后重新登录，检查版本是否更新。不要上传完整十六兆合并镜像、启动器或分区表。

## 20:08 装回前，做一次完整检查

功能确认后，再断电整理线束和绝缘，固定好模块并装回显示板盒。重新通电后，分别从网页、米家和苹果家庭测试开关、模式、温度和风速，观察实际动作和三端状态。若还保留原装模块，也检查它是否正常工作。

## 20:33 完成：按章节回看和排查

这套流程到这里就完成了。视频附带章节定位和字幕文件，你可以按接线、刷写、配网或设置单独回看。遇到问题先定位发生在哪一步，再检查那一步的接线、输入或状态。固件下载和更详细的文字说明，都可以回到教程网页查看。
