# 美的空调接入米家与 HomeKit：详细操作教程

成片按安装网页整理为 7 章、49 个步骤，涵盖显示板接口确认、逐根接线、电脑刷写、蓝牙与热点配网、管理网页、风速和密码、HomeKit、米家、状态诊断及 OTA。

## 交付文件

- `美的空调接入米家与HomeKit-详细教程-1080P.mp4`：1920×1080、25 FPS、H.264 / AAC，约 22 分 30 秒，烧录中文字幕并包含 MP4 章节。
- `详细教程-中文字幕.srt`：独立字幕。
- `详细教程-旁白与章节.md`：完整逐步讲解和时间轴。
- `章节定位.txt`：可用于播放器或视频平台的章节定位。
- `详细教程-封面.png`、`详细教程-画面总览.jpg`：封面与画面参考。

## 素材与呈现

刷机章节按原始时间顺序使用项目照片目录中的 `固件刷写.mp4`，从打开工具、选择镜像，到设置地址、开始写入和 FINISH。相关阶段局部放大；讲解较长的步骤会停留在最后一帧。录屏中的版本和 COM 端口是示例，以下载文件和实际端口为准。

接线章节使用项目实物照片与引脚表。蓝牙、Wi-Fi 和设备网页设置采用标注为“操作步骤示意”的界面图，使用示例网络与密码占位符。HomeKit 提醒使用设备当前显示的二维码和配对码，画面没有给出真实配对码。

中文旁白由 Windows 本机 Microsoft Huihui 引擎离线合成。字幕按照分段旁白编排。视频根据项目当前教程制作；不同板卡、空调型号和固件的功能以实际设备为准。

## 重新制作

编辑 `storyboard.py` 中各步骤的讲解和重点；`make_tutorial.py` 绘制图解并调用本机 FFmpeg 合成，`synthesize_local.py` 通过本机 SAPI 生成中文旁白。所需 Python 库为 Pillow、imageio-ffmpeg 和 pywin32。

在项目根目录运行：

```powershell
python ESP32-S3-主卧/docs/video-tutorial/make_tutorial.py --voice --frames --build
```

渲染缓存位于 `ESP32-S3-主卧/build/video-tutorial`。文稿修改后请先重新生成旁白。图形样式或字幕算法修改后，需要调整脚本的渲染版本以更新缓存。原始照片和录屏保留原样。
