接入你的 Wi‑Fi

通过蓝牙将附近的无线网络发送给设备。输入网络密码后，设备会保存设置并重启连接。

1连接设备
2选择网络
3保存设置

连接你的设备

打开蓝牙，搜索附近的 Midea Bridge。

与登录设备管理网页使用同一个密码。

Windows 首次使用时，若验证阶段配对失败，请先在系统蓝牙设置中配对此设备，再返回重新连接。

选择无线网络

设备将扫描附近可用的 2.4 GHz Wi‑Fi。

隐藏网络可以直接填写名称。

开放网络留空即可。

开始之前

开启设备蓝牙

确保设备已接通电源，并靠近你的手机或电脑。

准备网页登录密码

使用当前设备网页的管理密码完成身份验证。

确认网络为 2.4 GHz

ESP32 设备连接 2.4 GHz Wi‑Fi；5 GHz 网络不会出现在扫描列表中。

浏览器要求
请使用最新版 Chrome 或 Edge，并通过 HTTPS 网页或 localhost 打开。Safari 和 Firefox 暂不支持网页蓝牙。
